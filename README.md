# FlowsSynths
COmmodore 64 synth gemaak met Google Flows voor gebruik in jouw DAW.

Install:
 1. Download google flows plugin.
 2. Start jouw DAW zoals Logic Pro, Audacity 4, Cubase
 3. Voeg een midi rack toe en instrument GoogleFlows.
 4. Drag drop een fix-bestand in de plugin.
 5. Klaar. Genieten!
